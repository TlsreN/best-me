# 07 风格设计

三页结构的界面规范。想看某一版长什么样，直接说名字；风格清单在 [design/styles/索引.md](design/styles/索引.md)。

## 一、设计原则

1. **数字大，文字小**：手机上先看到的应该是「0 / 2197」，不是「热量摄入情况」。
2. **一张卡片一件事**：卡片之间靠底色区分，不描边框、不叠阴影。
3. **对齐成网格**：所有卡片左右各留 18px，内部元素四等分或三等分。
4. **圆角统一**：卡片 24，色块 15，小标签 9–14。不做混搭。
5. **颜色只承载数据**：界面本身是黑白灰，只有三个环有颜色（橙/蓝/红/青），颜色永远对应同一个宏量。
6. **空状态要好看**：没有数据时显示 `0` 与 `--`，不留破洞。

## 二、三页信息架构

| 页 | 一句话定位 | 卡片顺序 |
| --- | --- | --- |
| ① 首页 | 一屏看完今天 | 能量（大数字 + 四环）→ 快捷输入 → 日历 → 趋势小卡 ×2 |
| ② 数据 | 换算与速查 | 能量换算 → 食物速查 → 有氧消耗 → 今日细节 |
| ③ 身体 | 档案与计划 | 身体档案（✎ 编辑）→ 代谢 → 方向 → 体重记录 |

底部固定三标签：今天 / 数据 / 身体。

## 三、视觉规范

### 颜色

| 用途 | 值 |
| --- | --- |
| 页面底 | `#F1F1F3` |
| 卡片 | `#FFFFFF` |
| 主文字 | `#0A0A0B` |
| 次文字 | `#8B8B90` |
| 分隔线 | `#ECECEF` |
| 浅底块 / 图标底 | `#F4F4F6` |
| 蛋白 | `#E9A13B` |
| 碳水 | `#5B8DEF` |
| 脂肪 | `#E2605C` |
| 饮水 | `#33BFC4` |
| 强调（胶囊） | 字 `#1F8A6B` / 底 `#EAF6F2` |

### 字号

| 层级 | 大小 / 字重 |
| --- | --- |
| 页面标题 | 26 / 700，字距 -0.4 |
| 卡片标题 | 15 / 650 |
| 大数字 | 34–44 / 700，字距 -1 |
| 列表主文 | 13.5 / 400 |
| 标签、说明 | 11–12 / 400，次文字色 |

### 尺寸

- 卡片圆角 24，内边距 18
- 卡片间距 14
- 环直径 76，线宽 7，轨道透明度 0.16
- 图标容器 46×46，圆角 15，图标 22×22，线宽 1.7
- 日历格高 36，圆角 10

## 四、组件

| 组件 | 说明 |
| --- | --- |
| 能量头 | `0 / 目标 -- 大卡`，斜杠浅灰，右侧胶囊标方向 |
| 圆环 | 淡轨道 + 同色弧 + 起点圆点；中心是当前值；下方「标签 (单位)」+「0 / 目标」 |
| 快捷输入 | 六/七等分，图标 + 两字标签，点击直接开录入 |
| 日历 | 周一起始，当前日浅绿底，格内一个小圆点表示状态 |
| 迷你趋势 | 2×1 网格，浅底 16 圆角，标题 + 数值 + 30px 高折线 |
| 换算块 | 左右两个浅底方块，中间一个「=」 |
| 速查表 | 首列左对齐，数值右对齐，11px 表头 |
| 列表行 | 左标签右数值，行间 1px 分隔线，首行无线 |
| 分段控件 | 浅底轨道 + 白色滑块 + 投影 |
