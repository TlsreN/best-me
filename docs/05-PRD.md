## 1. 产品概述

**一句话**：给一个人用的健身记录本——每天记下吃了什么、练了什么、身体怎么变，用日历和图表回看，并按增肌或减脂方向算好明天该吃多少。

**要解决的问题**

1. 饮食方案在 Excel 里，每天要翻表算克数，坚持不下去。
2. 练了什么、重了多少，散在备忘录里，看不出进步。
3. 体重单日涨跌没有意义，但没人替你算趋势。

**成功标准**（三个月后回看，满足即算成功）

- 连续记录 ≥ 60 天，无中断超过 3 天
- 每天记录耗时 ≤ 60 秒
- 能回答「过去四周我的训练容量在涨吗」「这周平均摄入多少」
- 体重趋势与目标方向一致（增肌上行 / 减脂下行）

---

## 2. 目标与非目标

### 做

- 单用户、本地优先、离线可用
- 记录：饮食、训练、身体数据
- 计算：BMR / TDEE / 目标热量与三大宏量，口径与现有 Excel 完全一致
- 展示：日历 + 四张趋势图
- 数据可导出、可迁移，为将来原生版留接口

### 不做（首年）

- 账号体系、多设备实时同步、社交分享
- AI 拍照识别食物、自动生成食谱
- 接入第三方食物数据库（中餐数据质量差）
- 安卓、桌面端、手表独立 App

## 3. 用户与场景

**用户**：本人。男，24 岁，165 cm，63 kg，BMI 23.2，增肌期，午饭前训练，健身房三分化。

**一天的典型使用**

| 时间 | 动作 |
| --- | --- |
| 晨起 | 称重，记 63.2 kg |
| 早饭 | 鸡蛋+牛奶，记碳/蛋/脂 |
| 10:30 | 练前垫碳水（香蕉/小面包），记一条 |
| 11:00–12:15 | 训练，记 4–6 个动作的组×次×重量 |
| 12:30 | 午饭=练后餐，全天最大一顿，记完看进度条 |
| 19:00 | 晚饭，记完 |
| 睡前 | 看一眼「今日进度」，超了明天收着点 |

**核心情绪诉求**：别让我算，别让我填一堆，让我看得见进步。

## 5. 功能细则

### 5.1 今天

**字段**

| 区块 | 字段 | 规则 |
| --- | --- | --- |
| 顶部 | 日期、力训日/休息日 | 可左右翻日；点标签切换，切换后目标立刻变 |
| 身体 | 体重、体脂 | 数字，可空；填了体重会同步到方案里的体重，目标随之重算 |
| 饮食 | 餐次、食物名、克数、碳水、蛋白质、脂肪、热量、微量营养素 | 热量留空时按 `碳×4 + 蛋×4 + 脂×9` 自动算 |
| 训练 | 动作、组数、次数、重量、RPE | 同一天可加多条 |
| 有氧 | 项目、时长 | 消耗 = 每 kg 每小时消耗 × 体重 × 小时 |
| 进度 | 热量、碳水、蛋白质、脂肪 | 实时对比当日目标 |

**交互**

- 「+ 记一餐」弹出表单，餐次按当前时间猜默认值（<10 点早饭，11 点前练前，15 点前午饭，19 点前晚饭，其余加餐）
- 食物名带历史联想，减少重复输入
- 每条记录可删

**边界**

- 热量超过目标 1.15 倍时，进度条与提示变红
- 休息日的目标自动换成休息日那套

### 5.2 日历

- 月视图，周一为每周第一天
- 每格显示：日期、状态点、力训标记「练」
- 状态口径（摄入 ÷ 当日目标）：≤1.05 达标（绿）、1.05–1.15 略超（橙）、>1.15 超较多（红）、无记录（灰）
- 点任意一天 → 跳到该天的「今天」页
- 底部给本月汇总：有记录天数、力训天数、日均摄入

### 5.3 趋势

| 图 | 口径 |
| --- | --- |
| 体重 | 单日散点 + 7 日滑动平均线；只看均线 |
| 热量收支 | 近 14 天每日摄入柱 + 力训日目标虚线 |
| 宏量构成 | 当日三大宏量供能占比环形图 + 克数 |
| 训练容量 | 近 8 周 `Σ(重量 × 次数)` 柱状图 |

### 5.4 方案

- 方向切换：增肌（×0.84）/ 减脂（×0.64）
- 可改：性别、年龄、身高、体重、力训消耗、有氧消耗、蛋白系数、脂肪克数、碳水系数（力训/休息）
- 实时展示计算链：BMR → 无运动消耗 → 平衡热量（力训/休息）→ 应吃热量 → 三大宏量
- 数据区：导出 JSON、导出 CSV、导入 JSON、清空

## 6. 计算规范

```
BMR  = 9.99×体重 + 6.25×身高 − 4.92×年龄 + 5      （男）
     = 9.99×体重 + 6.25×身高 − 4.92×年龄 − 161    （女）
无运动消耗 = BMR ÷ 0.7
力训日平衡 = 无运动消耗 + 力训消耗 + 有氧消耗
休息日平衡 = 无运动消耗 + 有氧消耗
应吃热量   = 平衡热量 × 0.84（增肌） / × 0.64（减脂）
碳水 = 3.5 / 2.7 g/kg（增肌，力训/休息）；2.6 / 2.2 g/kg（减脂）
蛋白质 = 1.9 g/kg
脂肪 = 80 g（男增肌）/ 60 g（男减脂）
```

**注意**：三大宏量克数之和**不等于**热量目标，这是原表刻意的设计（预留约 20% 余地）。界面上两者都显示，不做「配平」。

## 7. 数据模型

核心实体：`Day`、`BodyMetric`（并入 Day）、`FoodEntry`、`WorkoutSet`、`Cardio`、`Plan`、`Target`（由 Plan 现算）。
字段与关系见 [01-数据模型与功能范围.md](01-数据模型与功能范围.md)。
