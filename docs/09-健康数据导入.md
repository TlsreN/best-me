# 09 健康数据导入

## 一、先说清楚限制

**网页应用（PWA）无法直接读 HealthKit。** 这是系统限制，不是没做：

- HealthKit 只对原生 App 开放
- 原生 App 需要 Mac + Xcode 编译，你没有 Mac
- 所以「打开 App 自动同步健康数据」这条路，当前走不通

能走通的是：**iOS 快捷指令读健康 → 写成一行文本 → App 导入**。
半自动：快捷指令可以定时自动跑，但 App 这边仍需你点一次「导入」。

## 二、数据格式

一行一天，逗号分隔，五个字段：

```
2026-11-13,412,1480,8342,35
```

| 位置 | 含义 | 必填 |
| --- | --- | --- |
| 1 | 日期 `yyyy-MM-dd` | 是 |
| 2 | 活动能量 kcal | 是 |
| 3 | 静息能量 kcal | 是 |
| 4 | 步数 | 否 |
| 5 | 运动分钟 | 否 |

头行（`date,active,resting,steps,workoutMin`）可以留，程序会跳过。

## 三、一次性配置快捷指令

1. 打开「快捷指令」App → 「+」新建 → 命名「导出健康」
2. 添加动作 **「查找健康样本」**
   - 类型选 **活动能量**
   - 筛选条件：`日期` `是今天`
   - 限制：关掉
3. 添加 **「计算统计信息」**：对上面的结果取 **总和**
4. 重复 2–3，再加一组 **静息能量** 取总和
5. 再加一组 **步数** 取总和（选填）
6. 添加 **「文本」** 动作，内容：

```
[格式日期: 今天, 格式 yyyy-MM-dd],[活动能量总和],[静息能量总和],[步数总和],0
```

把方括号里的内容换成对应的变量（长按插入变量）。

7. 添加 **「追加到文件」**
   - 路径：`iCloud 云盘/健康/health.csv`
   - 内容：上一步的文本
8. 到「自动化」→「+」→「时间」→ 每天 23:00 → 运行「导出健康」→ **关闭「运行前询问」**

## 四、每天怎么用

1. 快捷指令到点自动把今天那一行追加到 `health.csv`
2. 打开 App → 身体 → 设置 → **健康数据导入**
3. 点「从文件导入」→ 选 `iCloud 云盘/健康/health.csv`
4. 看到「导入 N 天健康数据」即可

也可以不建文件：直接把那一行文本复制，粘进「粘贴文本」框里导入。

## 五、导入之后会发生什么

- 这一天记下 `health = {活动, 静息, 步数, 运动分钟}`
- **总消耗改用「活动 + 静息」**，替代方案里的估算值
- 数据页多一块「消耗与结余」：摄入、消耗、结余，右上角标注「来自健康」
- 没导入的日子仍按方案估算，两者并存

> 注意：总消耗变了，但**目标热量不会自动跟着变**。目标仍按方案参数算，避免一天没同步就把目标带偏。要改目标去「训练与饮食方案」里调。

## 六、以后有 Mac 怎么做

原生版可以直接用 HealthKit：

- 后台自动同步，不用导入
- 能读心率、睡眠、训练明细
- 能耗不再靠估算

那时这套文本格式仍可作为「从旧版迁移」的通道。
