# 需求清单与取舍（待你拍板）

参照物：你最早那段需求原文。原则：**自用、能天天用下去**，不为「完整」加功能。

---

## 一、剥掉包装，核心只有 5 条

1. 快速记下今天吃了什么（碳水 / 蛋白 / 脂肪 / 热量）
2. 快速记下今天练了什么
3. 记下体重，看得出一段时间的趋势
4. 一眼看出今天达没达标（日历 + 进度条）
5. 根据趋势告诉你「该加还是该减」

其余全是从这 5 条派生的。任何功能如果不能让这 5 条更快或更准，就是负担。

## 四、建议删减（4 项）

| 项 | 为什么删 | 你会损失什么 |
| --- | --- | --- |
| **RPE 字段** | 你没要求过，练完没人会去填 1–10 分 | 几乎没有 |
| **宏量环形图** | 和进度条重复，看完不产生任何行动 | 一个好看的图 |

| **CSV 导出按钮** | JSON 备份已足够；CSV 只在你要扔进 Excel 时用 | 偶尔要时多点两下 |

## 七、当前做不到（不是删减，是没法做）

Apple 健康、手表、读另一个健身 App——三条全卡在同一件事上：**没有 Mac，拿不到 HealthKit**。

可选的两条路：

- **不折腾**：等以后有 Mac 再说。手动记体重并不痛苦。
- **绕一下**：用「快捷指令」把健康数据导成 CSV，我再写导入。缺点是得自己跑快捷指令，且只能拿到健康里有的数据。

我的建议是先不折腾，等你用满一个月，确认「每天称重」这件事你自己能坚持，再决定值不值得为它上云 Mac。
