# 10 本地化部署方案

目标：**不用开着电脑，手机上一打开就能用，数据不丢。**

## 一、先把「本地」拆成三个问题

很多人说「本地」，其实混了三件事：

| 问题 | 现在的状态 |
| --- | --- |
| 数据存在哪 | 已经存在手机浏览器里（localStorage），不上传任何服务器 |
| 应用从哪来 | 从我这台电脑的临时隧道来，电脑关机就没了 |
| 地址稳不稳 | **不稳**，隧道一重启就换域名，等于换了个新 App |

所以要解决的不是「数据本地化」，是**「应用固定地址化」**——地址不变，数据才认得回自己的家。

## 二、四条路

| 方案 | 要开电脑 | 要 Mac | 地址固定 | 离线可用 | 接健康 | 成本 |
| --- | --- | --- | --- | --- | --- | --- |
| ① 现状：本地服务 + 隧道 | 要 | 不要 | ❌ 每次变 | ❌ | 否 | 0 |
| ② **静态托管 + 添加到主屏幕** | 不要 | 不要 | ✅ | ✅ | 否 | 0 |
| ③ 单文件 HTML 存「文件」App | 不要 | 不要 | ✅ | ✅ | 否 | 0 |
| ④ 原生 App（云 Mac） | 不要 | 要 | — | ✅ | ✅ | 30–100 元/月 |

### ① 现状的问题

隧道是 cloudflared 的免费 quick tunnel，每次启动随机分配域名。
**换域名 = 换 origin = 数据全部「看不见」**（不是丢了，是找不到）。

2026-11-14 重启后就发生了这件事：旧地址 `second-revealed-…` 下的记录，在新地址 `int-social-helmet-sims-…` 里打不开。

### ② 推荐：静态托管 + 添加到主屏幕

把 `app/` 目录（7 个文件，不到 80 KB）传到任意免费静态托管，得到一个固定域名：

- 域名永久不变 → 数据永远在
- Service Worker 缓存全部文件 → **断网也能开**
- Safari「添加到主屏幕」→ 全屏、无地址栏、图标在桌面
- 打开即用，自动保存，不需要电脑

可选托管（都免费、都支持自定义域名）：

| 平台 | 优点 | 缺点 |
| --- | --- | --- |
| GitHub Pages | 与代码同仓，`git push` 即发布 | 需 GitHub 账号 |
| Cloudflare Pages | 国内访问相对稳 | 需 Cloudflare 账号 |
| Netlify Drop | 拖文件夹即可，最快 | 需账号保管部署 |

### ③ 不推荐：单文件 HTML

理论上可以把它存进「文件」App，用 Safari 打开。但：

- iOS 对 `file://` 页面的本地存储支持不稳定，可能每次打开都是空的
- 没有 Service Worker，不能离线缓存
- 没有桌面图标，每次要翻文件

**数据不能放这儿。**

### ④ 以后：原生 App

只有这条路能真正「在手机上跑」并直连 HealthKit：

- 需要 Mac（自购 / 借用 / 租云 Mac）
- 需要 Apple 开发者账号（688 元/年）才能长期装在手机上
- 好处：后台自动同步健康数据、Apple Watch、可上架

## 三、结论

**先做 ②。** 它用 0 元、0 台 Mac，解决了 95% 的痛点：
不用开电脑、地址固定、离线可用、数据留在手机。

**④ 等你确认自己会长期用再说。**

## 四、已经上线了（2026-11-14）

以后改了代码，发布一条命令：

```powershell
powershell -ExecutionPolicy Bypass -File tools\deploy.ps1 -Message "改了什么"
```

约 30–60 秒生效。

## 五、②的执行步骤（已完成的留档）

1. 建一个 GitHub（或 Cloudflare）账号
2. 我把 `app/` 推上去，开启 Pages
3. 拿到 `https://<用户名>.github.io/<仓库>/`
4. iPhone Safari 打开 → 分享 → 添加到主屏幕
5. 在旧地址点「备份」导出 JSON → 在新地址「导入」搬过去

第 5 步只有一次，之后地址不再变。

## 六、数据安全底线（不管用哪条路）

- 每周点一次「备份」，存到「文件」App
- 换地址、换浏览器、清理缓存前，**先导出**
- 导出文件是纯 JSON，十年后也能读
