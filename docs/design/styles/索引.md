## 命名规则

- 文件：`S<两位编号>-<中文名>.png`，源文件同名 `.html`，放在本目录
- 名字 2–4 个字，要能一眼想起长什么样（如「清爽白卡片」「深色数据流」）
- 编号只增不减、不复用；不喜欢的版本在表里标「已弃用」，文件保留

## 怎么用

- 「用 S01」或「用清爽白卡片」都行
- 「在 S01 基础上把圆角改小」= 以此版为基线出一版新的，编号 +1

## 怎么加一版

1. 复制最新的 `.html`，改成新名字，如 `S02-深色数据流.html`
2. 改文件顶部的 CSS 变量（颜色、圆角、字号）与组件样式
3. 渲染预览图：

```powershell
powershell -ExecutionPolicy Bypass -File tools\render-style.ps1 -Name S02-深色数据流
```
