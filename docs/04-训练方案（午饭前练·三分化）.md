# 04 训练方案（午饭前练 · 三分化）

数据来源：`reference/健身饮食.xlsx` → 工作表「19 训练计划-健身房三分化」。默认采用三分化：你属于有基础（BMI 23.2、已在增肌），三分化或四分化都可以，先用三分化跑稳。

## 一、总参数

| 项 | 要求 |
| --- | --- |
| 频率 | 每周 3–5 次；连续两周做不到 3 次，本方案作废 |
| 单次时长 | 1–1.5 小时，总组数 20 组上下 |
| 配重 | 多数动作选能标准做 6–12 次的重量；新动作可 12–15 次；偶尔 3–5 次冲力量 |
| 力竭 | 深蹲、卧推、推举**留 1–2 次不做到力竭**；其余可做到力竭 |
| 组间休息 | 胸 / 背 / 臀腿 2–3 分钟；肩 / 手臂 2 分钟；最低不低于 1.5 分钟 |
| 时间 | 午饭前练 → 午饭为练后餐（见 docs/03） |

## 二、Day 1：背 + 肩后束 + 肱二头

| 部位 | 组数 | 动作（任选） |
| --- | --- | --- |
| 背·下拉 | 选 1–2 个动作，共 6–8 组 | 引体向上（宽握）/ 高位下拉（中握）/ 器械下拉（窄握） |
| 背·划船 | 选 1–2 个动作，共 6–8 组 | 杠铃俯身划船 / T 杆俯身划船 / 坐姿器械划船 / 单边哑铃划船 / 龙门架直臂下压 |
| 肩后束 | 选 1–2 个动作，共 6–8 组 | 哑铃俯身飞鸟 / 蝴蝶机反向飞鸟 / 龙门架反向飞鸟 / 水平开肘划船 |
| 肱二头 | 选 1–2 个动作，共 6–8 组 | 哑铃弯举 / 杠铃弯举 / 集中弯举 / 器械弯举 / 牧师椅弯举 |

## 三、Day 2：胸 + 肩前中束 + 肱三头

| 部位 | 组数 | 动作（任选） |
| --- | --- | --- |
| 胸·中胸 | 选 2–3 个动作，共 10 组 | 杠铃/哑铃/史密斯卧推、器械推胸、蝴蝶机夹胸、龙门架夹胸 |
| 胸·上胸 | 新手偶尔加，1 个动作 4 组 | 上斜卧推 / 上斜器械推胸 / 上斜夹胸 |
| 胸·下胸 | 新手偶尔加，1 个动作 4 组 | 下斜夹胸 / 下斜推胸 / 双杠臂屈伸（前趴 30–60°） |
| 肩前束 | 1 个动作 5 组 | 器械/哑铃/史密斯推举、前平举 |
| 肩中束 | 1 个动作 5 组 | 哑铃/龙门架侧平举、杠铃提拉 |
| 肱三头 | 1 个动作 5 组 | 龙门架下压、绳索臂屈伸、颈后臂屈伸、窄距卧推 |

## 四、Day 3：腿臀 + 腹

| 部位 | 组数 | 动作（任选） |
| --- | --- | --- |
| 股四头肌 | 选 1–2 个，共 6–8 组 | 杠铃深蹲 / 器械腿屈伸 |
| 腘绳肌 | 选 1–2 个，共 6–8 组 | 罗马尼亚/传统硬拉 / 器械腿弯举 |
| 臀大肌 | 选 1–2 个，共 6–8 组 | 器械臀冲 / 杠铃臀冲 |
| 兼练 | 选 1–2 个，共 6–8 组 | 哈克机 / 倒蹬机 / 箭步蹲 / 史密斯深蹲 |
| 腹 | 选 1–2 个，共 6–8 组 | 平板卷腹 / 悬垂举腿 |

> 股四头、腘绳、臀大肌三个大肌群不要塞进同一次训练，按周轮换：
> 男：第一次 股四 + 兼练 → 第二次 腘绳 + 兼练 → 第三次 臀大肌 + 兼练，依此循环。

## 五、增肌 vs 减脂，训练上的差别

| | 增肌 | 减脂 |
| --- | --- | --- |
| 力训 | 3–5 次/周，**必须有**，掉了就没进步 | 3–5 次/周，作用是**保肌**，不直接减脂 |
| 有氧 | 一般不做 | 体重 <70 kg 每周约 2 小时；70–80 kg 先不做、饿了再加；>80 kg 不做 |
| 有氧位置 | — | 力训前不做；力训后 ≤30 分钟；超过 30 分钟要与力训隔开几小时或放休息日 |
| 有氧强度 | — | 心率 120–150 次/分，不必严格 |
| 热量关系 | 靠饮食盈余 | 缺口由饮食提供；多做有氧可等量多吃（+100 kcal 有氧 = +100 kcal 饮食） |

## 六、App 里怎么落

- **计划**页存这套三分化模板（部位 → 动作池 → 建议组数）
- **今天**页只记：选哪个 Day、每个动作做了几组几次多重
- **趋势**页算 `tonnage = Σ(重量 × 次数)`，按周对比，看训练量是否在涨
- 减脂方向时，若饮食已执行到位但两周不掉秤，才提示加有氧（对应 docs/03 的规则）
