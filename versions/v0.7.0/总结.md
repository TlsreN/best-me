# v0.7.0 内容总结

- 日期：2026-11-13
- 类型：**输入方式重构**（按顿记营养、按总运动量记训练）
- 状态：可用

## 1. 本次输入

> 你做这个看不懂，按每顿饭摄入营养来算，运动量按总运动量来输入，不按照单个动作来输入

判断：不是界面不好看，是**记录的动作太多**。一条午饭要拆成米饭/鸡胸/青菜三条，一次训练要拆成四个动作，填一次要点十几次。

## 2. 改了什么

| 原来 | 现在 |
| --- | --- |
| 一条食物一条记录（名称、克数、碳蛋脂、热量、微量） | **一顿一条**（碳水、蛋白、脂肪、热量、备注） |
| 一个动作一条记录（动作、组、次、重量） | **一次训练一条**（总消耗、总容量） |
| 有氧单独一条一条加 | 同一个人「记训练」弹层里填项目+分钟 |
| 自定义食物库（每 100 g / 每份） | **删除**，不再需要 |

数据结构从 v2 升到 v3（存储键 `zghd.v3`），旧数据自动汇总：

- 多条食物 → 按餐次相加成一条
- 多个动作 → 汇总成一条力量记录（消耗相加、容量相加）
- 多条有氧 → 汇总成一条（分钟相加）

迁移链 `v1 → v2 → v3` 都在 `normalize()` 里，测试覆盖。

## 3. 界面变化

- 记一餐：一个表单，三个数字 + 热量（可空）+ 备注，顶部提示「合计约 X 大卡」
- 记训练：力量（总消耗、总容量）+ 有氧（项目、分钟）两段，一个保存
- 数据页：去掉自定义食物，换成「这一天吃了什么」五餐明细
- 首页不变
