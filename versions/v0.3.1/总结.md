### 2.2 Git 仓库

- `git init -b main`，首次提交 `2db3290`
- 纳入 59 个文件，仓库 0.5 MB
- `.gitignore`：`reference/*.xlsx` 不入库

**为什么排除原表**：58 MB，其中 57 MB 是 38 张插图；表格的文字内容已解析进 `reference/excel-解析/*.tsv`，检索能力不受影响，克隆与部署速度却快很多。想连原表一起备份，注释掉那行即可。

**为什么用 Git 而不是只靠 `versions/` 文件夹**：

| | `versions/` 文件夹 | Git |
| --- | --- | --- |
| 记录「改了什么、为什么」 | 能 | 能 |
| 回到任意一天的文件状态 | 不能 | 能，一条命令 |
| 误删误改后恢复 | 不能 | 能 |
| 部署到 GitHub Pages | 不能 | 必须 |

两者不冲突：`versions/` 管「决策史」，Git 管「文件史」。
