### 2.2 GitHub 准备

- 尚未登录，等待一次性设备码授权

## 3. 结论：不需要给账号密码

给密码是错的；给长期 token 也不合适。正确做法是一次性授权：

```
我发起 gh auth login  → 打印 8 位设备码 → 你在浏览器输入 → 完成
```

之后我可以：建仓库、推送、开 Pages、以后每次改动直接提交推送。凭据存在本机凭据管理器，不经过对话。

## 4. 为什么最终要上 GitHub Pages

- 隧道地址每次重启都变，做成主屏图标后会变成死链
- Pages 是固定地址，`https://<用户名>.github.io/<仓库名>/`，免费、无需服务器
- 顺带把 Git 仓库推到远程，等于异地备份
