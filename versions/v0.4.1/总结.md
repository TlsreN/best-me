## 2. 做了一件防止丢数据的事

**新增顶栏「备份」按钮**：一键导出整份 JSON 到「文件」App，同时记录备份时间；方案页会显示「今天已备份 / N 天前备份 / 还没备份过」。

为什么现在做这个：记录数据存在浏览器里，而浏览器存储按**网址**隔离。测试用的公网地址是一次性的，隧道重启就会换一个地址——换了地址，打开就是个空 App，旧数据还在旧地址下，但你已经打不开了。

所以必须先让对方手上随时能拿到一份 JSON。这是「能记录」的前提，不是锦上添花。
