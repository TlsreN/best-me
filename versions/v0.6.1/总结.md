# v0.6.1 内容总结

- 日期：2026-11-13
- 类型：**按 PRD v2.0 重写应用**（三页结构落地）
- 状态：可用，待真机验收

## 1. 做了什么

### 1.1 数据层重写（`app/store.js`）

存储键升到 `zghd.v2`，并带 v1 → v2 一次性迁移：

- **训练消耗拆分**：`Workout` 与 `Cardio` 两张表，各自记 kcal；平衡热量用合计
- **趋势聚合**：`trend(state, 'day'|'week'|'month', date)`，缺失值返回 `null` 不补零
- **两种食物计量**：`Food.mode = per100g | perServing`，`foodMacros()` 统一换算
- **迁移**：v1 的 `sets[]` 收编成一条 `Workout`，`foods` 补 `mode:'manual'`

### 1.2 界面重写（`app/ui.js` + `styles.css` + `index.html`）

三页 + 六个弹层：

| 页面 | 内容 |
| --- | --- |
| 今天 | 日期 + 力训日切换、能量卡（大数字 + 四环）、六个快捷输入、趋势（日/周/月 + 双折线） |
| 数据 | 月历（状态点 + 力训底 + 今日/选中）、当日达标五条、自定义食物列表、能量换算 |
| 身体 | 身体档案、记录体重（输入 + 最近三条 + 7 日均值）、设置三项 |

弹层：记一餐、记训练、记有氧、记饮水、记录体重、新增/编辑食物、方案、备份、关于。

### 1.3 视觉

按 S02 单屏版落地：浅灰底、纯白卡片 22 圆角、四环 72px/线宽 7、六个快捷图标。
iPad ≥900px 时首页自动变两栏（能量 + 快捷并排，趋势通栏）。
