## 1. 本次输入

## 2. 建了什么

### 2.1 风格库目录

```
docs/design/styles/
├─ 索引.md                    ← 名字 → 文件 的对照表
├─ S01-清爽白卡片.html         ← 可改的源文件
└─ S01-清爽白卡片.png          ← 1420×1100 渲染图
```

命名规则：`S<两位编号>-<中文名>`，图与源文件同名，编号只增不减。

调用方式：说「用 S01」或「用清爽白卡片」都可以。

### 2.2 规范文档

`docs/07-风格设计.md`：六项设计原则、三页信息架构、颜色/字号/尺寸表、九种组件定义、风格清单、待定项。

### 2.3 渲染脚本

`tools/render-style.ps1`：一条命令把某个风格稿重新渲成图。

```powershell
powershell -ExecutionPolicy Bypass -File tools\render-style.ps1 -Name S01-清爽白卡片
```

过程中踩到两个坑，都已修：

1. 用 pwsh 的 `Get-Content -Raw` 处理 UTF-8 文件会把中文读成乱码（按 GBK 解码），导致整份 HTML 二次编码损坏 → 教训：**这类文件只用编辑工具改，不用 shell 文本管道改**
2. `$ErrorActionPreference='Stop'` 会让 Edge 往 stderr 写的无关日志变成本脚本的报错 → 调用期间临时改为 `Continue`
