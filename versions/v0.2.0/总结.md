## 2. 逐条决定

| 要求 | 落地方式 |
| --- | --- |
| 只有 iPhone + iPad，优先 iPad | 界面 iPad 优先（日历+详情双栏），iPhone 自适应；但见下方「无 Mac 限制」 |
| 自用，预留上架接口 | 数据模型用 JSON Schema、导出格式固定、业务逻辑与 UI 分层 |
| 数据存本地 + 导出 | IndexedDB 本地存储；`full-backup.json` 全量备份 + `day.csv` 可读导出 |

| 读另一个健身 App 的运动量 | 该 App 若写入「健康」即一并读出；具体是哪个 App 待确认 |
| 食物手动输入 + 营养分类 | 录入表单固定给「碳水 / 蛋白质 / 脂肪 / 热量 / 微量营养素」五区，实时显示当日剩余配额 |
| 按 Excel 午饭前练做双方向 | 见 `docs/03`、`docs/04`，参数与规则全部取自表格 |
