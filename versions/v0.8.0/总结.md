## 2. 四条改动

### 2.1 刷新按钮

「今天」标题右边加了个 ↻，点了重新加载页面。不用再彻底关掉重开。

### 2.2 两个卡片合并

快捷输入（六个图标）搬进能量卡，用一条分隔线隔开。少了一张卡的外框和间距，实测在 500×844 下整页高度约 690px，一屏放得下。

### 2.3 方向可点

能量卡右上角的「增肌」变成按钮，点一下直接切到「减脂」，目标立刻重算。详细参数仍在 身体 → 设置 → 训练与饮食方案。

### 2.4 日历状态改为四项判定

原来只看热量比例，现在看**热量、碳水、蛋白、脂肪**四项：

| 状态 | 条件 | 颜色 |
| --- | --- | --- |
| 全达标 | 四项都在 90%–110% | 绿 |
| 有一项没达标 | 任一项 <90%，或某项 110%–120%，但没超过 120% | 荧光黄 `#E2F51A` |
| 超出太多 | 任一项 >120% | 红 `#D2362B` |
| 无记录 | 没有数据 | 灰 |

阈值写在 `store.js`：`RANGE = { low: .90, high: 1.10, over: 1.20 }`。

饮水不参与判定——它没有「吃超」的概念。

## 3. 副作用（要提前说）

按这个规则，**多数日子会变黄**。因为四项同时落在 ±10% 里很难做到，尤其蛋白：少吃一口就掉到 90% 以下。

半年测试数据里，13 号是绿的（2024/2197、220/221、114/120、76/80），其余大多黄。

想放宽的话改两个数即可，例如 `low: .85, high: 1.15`。

## 4. 测试

`tools/test_store.js` **74 项全过**，新增 4 项状态判定：

- 四项都在 90–110% → good
- 蛋白偏低 → warm
- 碳水超 120% → over
- 空日 → empty
