# 最好的我 · 项目导航

个人自用的 iOS/iPad 应用：记录每日饮食、训练与代谢数据，用图表与日历回看，并根据输入的数据调配训练与饮食计划。

当前形态：**PWA 网页应用**（原因见 [docs/02-技术路线与限制.md](docs/02-技术路线与限制.md)：没有 Mac，原生与 HealthKit 暂时做不了）。

## 先跑起来

```powershell
powershell -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8080
```

脚本会打印局域网地址，在 iPad / iPhone 的 Safari 里打开 `http://<那个地址>:8080`，
再点「分享 → 添加到主屏幕」，就有了全屏的「最好的我」。

## 现在能做什么

- 记一天：体重体脂、五餐食物（碳/蛋/脂/热量/微量营养素）、训练动作、有氧
- 看进度：热量与三大宏量对目标的完成度
- 翻日历：每天的达标状态与力训标记
- 看趋势：体重均线、热量收支、宏量构成、训练容量
- 切方向：增肌 ↔ 减脂，参数与目标实时重算
- 备份：导出 JSON / CSV，可再导入

## 已知约束

- 只有 iPhone + iPad，没有 Mac → 原生 iOS 无法本地编译，HealthKit 用不了
- 数据存浏览器本地，长期不用可能被系统清理 → 每周导出一次 JSON
- 需要部署到 https 才能稳定「添加到主屏幕」（本地 `http://` 也行，但离线缓存需 https 或 localhost）

## 版本控制

已建立本地 Git 仓库，分支 `main`。

```powershell
git add -A
git commit -m "vX.Y.Z 一句话说明改了什么"
git log --oneline          # 看历史
git checkout -- app/ui.js  # 改坏了，丢弃未提交的改动
```

- `versions/` 记「为什么这么改」，Git 记「文件当时长什么样」，两者分工不重叠
- `reference/*.xlsx` 不入库（58 MB，内容已解析成文本）；要连原表备份，注释掉 `.gitignore` 里那行
- 尚未推送远程。日后接 GitHub Pages 时再加 remote，届时需要把提交身份改成你 GitHub 账号的邮箱
