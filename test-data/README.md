# test-data

测试用数据。两个文件，用途不同。

| 文件 | 给谁用 | 说明 |
| --- | --- | --- |
| `每日记录模板.xlsx` | 你 | 空白模板，已填好 2026-11-13 一天作基准，照格式往下加 |
| `半年增长数据.json` | 程序 | 以基准日推演 180 天，导入 App 自测用 |

## Excel 怎么填

四个工作表：

**填写说明** —— 规则都在这页

**每日概览**（一天一行）
`日期` `力训日` `体重 kg` `饮水 ml` `备注`

**饮食**（一条食物一行）
`日期` `餐次` `食物` `数量` `碳水 g` `蛋白 g` `脂肪 g` `热量 kcal`

- 餐次只能填：早饭 / 练前 / 午饭 / 晚饭 / 加餐
- 数量写人类看得懂的量：`350 g`、`1 根`、`2 个`、`250 ml`
- 热量留空也行，程序按 `碳×4 + 蛋×4 + 脂×9` 算

**训练**（一个动作一行）
`日期` `类型` `名称` `组数` `次数` `重量 kg` `分钟` `消耗 kcal`

- 类型写 `力量` 或 `有氧`
- 有氧只填 `分钟`，组次重量留空

## 半年数据是怎么造的

- 180 天：2026-05-18 → 2026-11-13
- 体重 63.2 → 66.1 kg，线性增长 + 日常波动 + 每日水分起伏
- 每周一三五力量，周间两次有氧，每两周加深蹲/硬拉 2.5 kg
- 热量按目标缩放米饭克数，训练日约 2250、休息日约 1980，带 ±6% 波动
- 10% 的餐次随机标成「外食」并改变热量与脂肪
