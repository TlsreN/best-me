| `每日记录模板.xlsx` | 你 | 空白模板，已填 2026-11-13 一天作基准 |

## Excel 怎么填

**每日概览**（一天一行）
`日期` `力训日` `体重 kg` `饮水 ml` `备注`

**饮食**（一顿一行，不拆食物）
`日期` `餐次` `碳水 g` `蛋白 g` `脂肪 g` `热量 kcal` `备注`

- 餐次只能填：早饭 / 练前 / 午饭 / 晚饭 / 加餐
- 热量可以留空，程序按 `碳×4 + 蛋×4 + 脂×9` 算
- 备注写这顿吃了什么，如「米饭+鸡胸+青菜」

**训练**（一次一行，不记动作）
`日期` `类型` `名称` `消耗 kcal` `分钟`

- 类型写 `力量` 或 `有氧`
- 力量填总消耗，`分钟` 留空；有氧填项目名与分钟
